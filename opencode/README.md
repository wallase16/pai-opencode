# OpenCode PAI Adapter

This directory contains the **PAI Adapter** for OpenCode, enabling seamless integration between OpenCode and the Personal AI Infrastructure.

## Directory Structure

*   **`plugin/`**: Contains the core adapter source code (`pai-adapter.ts`) which bridges OpenCode events and PAI workflows.
*   **`scripts/`**: Helper scripts for setup, verification, testing, and maintenance.
*   **`voices/`**: Configuration and models for the Piper TTS voice system.

## Key Files

*   `plugin/pai-adapter.ts`: The main plugin logic.
*   `scripts/setup-adapter.sh`: Automates the installation and configuration of the adapter.
*   `scripts/verify-pai.sh`: Verifies that the PAI integration is working correctly.

## Usage

See the root `PAI_MIGRATION_PLAN.md` or `docs/` for more detailed usage instructions.
