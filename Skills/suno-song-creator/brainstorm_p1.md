# Brainstorming: Suno Song to YouTube Pipeline

## Current Context
- **Tool**: `suno_chrome_creator.py` (Existing, handles generation & download).
- **Input**: CSV file (Song meta: Title, Style, Lyrics).
- **Goal**: End-to-end automation from CSV row -> Song Generation -> Video Creation (Song + Thumbnail) -> YouTube Upload.
- **Constraints**: Daily release cadence.

## Key Questions to Refine the Architecture

I need to understand the "Video Creation" and "Upload" components better to design the full pipeline.

**Question 1: Visuals & Thumbnails**
How do you want to handle the visual component of the video?
A. **Static Image**: Use the album art generated by Suno (if accessible) or a pre-defined image.
B. **AI Generated**: Generate a *new* image using DALL-E/Midjourney/Stable Diffusion based on the song lyrics/title.
C. **Dynamic Visualization**: Use a simple ffmpeg visualizer (waveform) over a background.

*My Recommendation*: Option A (Suno Art) is easiest if extractable. Option B (New AI Art) yields higher quality "custom" thumbnails for YouTube click-through.

**Question 2: YouTube Upload Method**
How should we upload to YouTube?
A. **YouTube Data API (Official)**: Requires Google Cloud project, OAuth setup, quota limits (6 videos/day usually). Reliable but bureaucratic setup.
B. **Browser Automation (Selenium/MCP)**: Use the same technique as Suno—log into YouTube Studio via Chrome and automate the upload form. No API limits, but more brittle.
C. **Manual Staging**: Generate the file, you upload it manually. (Least automated).

*My Recommendation*: Option B (Browser Automation) fits your existing `suno_chrome_creator` pattern and avoids API quota headaches for a personal project.

**Question 3: Scheduling**
Do you want the script to:
A. **Run Once Daily**: A cron job triggers the script, it processes *one* row, makes video, uploads immediately.
B. **Batch & Schedule**: Process *all* rows in CSV now, generate 10 videos, upload them all to YouTube as "Scheduled" for future dates.

*My Recommendation*: Option B (Batch & Schedule). It's more robust. You can verify the batch over the weekend and let it drip-feed.
